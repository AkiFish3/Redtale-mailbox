## 硬坑（通用，跨环境适用）

1. 浮层必须最后画：tooltip / 下拉 / 确认框 / 光标物品 / 涟漪 —— MC 是立即模式渲染，后画的覆盖先画的。踩过 3 次（tooltip 被格子盖、下拉被底栏盖、确认条被搜索框盖）。
2. 图标类控件用几何绘制：关闭 X、勾、箭头不要用字形居中，MC 字体字形本身不居中（`×` 右偏）。用两条斜线占位。
3. 原版主题不要拉伸 `generic_54.png`：底部会露出物品栏花纹、接缝错位。用"灰底 + 左上亮边 + 右下暗边"画窗口。
4. `widgets.png` 按钮是固定 20 高：调用方按中心对齐（`y + h/2 - 10`），不要用 `-3` 硬偏移。
5. `drawItemInSlot` 负责数量/耐久条：自己算坐标必错（踩过：数量画到图标下方）。
6. `render_type` 在 1.20.1 本实例不生效：渲染层由脚本/代码决定，别指望模型 JSON。
7. 搜索框/输入框必须有焦点才收字符：否则 Q、数字键会被吞。
8. 自绘容器要"镜像 + 本地预演"：客户端先改镜像再发包；判断"手里有没有东西"读镜像 `CURSOR`，不要读服务端快照（滞后一帧）。
9. 拖拽不要依赖 `mouseDragged`/`mouseReleased` 事件：自定义 Screen 不保证派发。用 `GLFW.glfwGetMouseButton` 轮询，或记录经过的格子、松手一次性提交。
10. 点击优先级 = 视觉层级：确认条在搜索框上方时，`mouseClicked` 必须先判确认条，否则点"确认"变成聚焦搜索框。
11. 协议 record 改字段时 encode/decode + 所有构造点同步改：漏一处就联机断连（踩过 3 次）。
12. 查询类命令必须静默（`/checkin status` 等）：只发快照不打印，否则每次开界面刷屏。
13. Hub 内命令不刷聊天：成功与失败都走 actionbar（`sendMessage(text, true)`）。
14. `peek()` 不读盘：首次打开界面要显示数据，用 `of()` 之类会加载的入口（踩过：仓储首开显示"无空间"）。
15. 覆盖运行中游戏的 jar 会 `ZipException`：用 `_sync_jar.py`（运行中写 `_pending`，关闭后 `--force`）。
16. 进程检测不要用 `wmic`：Win11 24H2 已移除，异常会被当成"游戏在跑"，jar 永远卡在 `_pending`。用 CIM 查询 `javaw` 的 CommandLine，只认 `net.fabricmc` / `net.minecraft` / `--gameDir`。
17. `runClient` 不读 `mods/` 目录：dev 环境用 `libs/dev/*.jar` + `modRuntimeOnly`（本工程已配）。
18. 同一工程并发 gradle 会抢锁：多队列必须用 `_build_lock.py`，被占返回 3 → 本轮不构建。
19. 旧模 modid 并入要统一：`redtale:` → `redtale_economy:`（已定：不保留旧命名空间，接受旧存档物品失效）。
20. 改名和改逻辑分开提交：混在一起出问题无法二分定位。
21. mixin 移植要能单独禁用：`SlotMixin` 改槽位行为，和容器类 mod 冲突概率最高。
22. 包名手滑：`net.akira...` vs `com.akira...`，编译立刻报"找不到符号"，别以为是依赖问题。
23. bash heredoc 里的反斜杠会被吞：正则 `\s` 变 `/s`，导致扫描恒 0 结果（假绿）。写脚本用 Write 工具落文件再执行，不要用 `python -c` 带转义。
24. `libs/dev` 只能放纯代码/纯资源模组，不能放 sodium / iris 这类优化模组：它们把 `method_XXXX` / `class_XXXX`（intermediary 名）硬编码在 `@Inject(method=…)` 里且不带 refmap，而 dev 环境是 yarn 命名的；loom 的 remap 只重写 refmap、改不动注解字符串 ⇒ 启动即 `MixinApplyError`（`BufferBuilder.method_23918` / `Identifier.method_20208`）。`modRuntimeOnly` / `modLocalRuntime` / `modImplementation files()` 三种写法全崩，不是配置问题，是这类 jar 在 dev 里根本不能用。判据：日志出现 `No refMap loaded` + 目标是 `method_\d+` ⇒ 直接移出 dev 运行时（本工程放 `libs/dev/_disabled/`）。
25. `compileJava` UP-TO-DATE ≠ 依赖没变：Gradle 对 classpath 做 ABI 归一化，只改依赖版本而源码不引用其类时任务会跳过。要证明「新依赖真进了编译类路径」，必须写一个临时引用其类的探针文件编一次，再删掉重编（删完要确认 `build/` 与产物 jar 里 0 残留）。
