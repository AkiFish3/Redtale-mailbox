## 1. 为什么会有「换账号」这件事

| 日期 | 变更 | 后果 |
|---|---|---|
| 2026-10-21 | 用 WorkBuddy **资料库空间**（`WPmfIEC…`）当两台机器的中转：跨机消息、规则包、快照都往那个空间上传/下载 | 双方靠同一个账号的资料库权限通信 |
| 2026-11-02 | 更换 WorkBuddy 账号 | 旧空间 `no read access`。S1 的上传、S3 的收信**同时失效**，等于信箱被拔线 |
| 2026-11-02 | 改为**私有 Git 仓库** `Redtale-mailbox` 中转 | 不再依赖任何账号的云空间权限；本仓库即信箱 |

一句教训：**中转介质不要挂在会变的账号上**。现在是"命名即所有权"（`D-` 前缀归开发机、
`S-` 前缀归服务器机），两边各写各的方向，不需要谁给谁授权。

同一时期还有一次账号侧的收口：Wiki 的登录从自建账号改成**直接校验 EasyAuth 账号库**
（`E:\server\EasyAuth\easyauth.db`，BCrypt，只读）。旧的自建管理员账号清掉了，
`wiki_admins` 里的游戏 ID 登录后自动是管理员。详见 `wiki/README.md`。

## 2. 两个服务器在同一台机器上

| 服 | 版本 | 路径 | 状态 |
|---|---|---|---|
| 旧服 | 1.20.1 **Fabric** + EasyAuth | `E:\server` | 仍在跑，作为存档与玩家过渡 |
| 新服 | 1.21.1 **NeoForge**（228 jar） | `E:\server-1.21.1` | 主目标 |

两服**同时在线**（2026-10-24 实测各约 27~32 小时连续运行，工作集 11.5 / 11.9 GB），
内存各给 12 G / 16 G，合计 28 G 已逼近本机 31.9 G 物理上限——双活期新服若涨到 Xmx，
得给旧服让路。这条约束记在 `_srv_PLAN_NEXT.md` 1.5.2。

两服都 `online-mode=false`，走离线 UUID，所以同一批玩家的身份在两端对得上。

## 3. 未寻旅境（在运营）

- 版本 1.20.1，**同一版本、同一语言、同一批玩家池**，比海外案例更有参照价值。
- 对外定位原话：「种田建筑旅游**副本**模组服务器」。
- 招新方式是**限时招新**，不是常开。
- 公开记录只有 B 站玩家专栏（2024-07-28）与招新视频标题，内容以玩家自建住宅组图为主。
- 关服/白名单相关的公开说明：**搜不到**（`[无有效结果]`，不编）。

**对赤物语的意义**：种田 / 建筑 / 旅游 / 副本这四个词**已经被占用**。
1.3 的候选定位必须避开这四个词的平铺直叙——「盖楼、做饭、串门的地方」反而更稳，
因为它说的是**关系**，不是**玩法清单**；玩法清单谁都能抄，串门抄不走。

## 4. 北岸枫林（已关闭）

- 1.20.1 **Fabric**，对外定位「生存\|建造\|烹饪\|冒险\|社交」。
- 与赤物语的**七项重合**：同版本同加载器、同样"生存+建造+烹饪+社交"、同样做聚落、
  同样用传送石碑、同样装语音模组（长按 F）、同样有官方副本与屠龙战。
- 三处差别：它**有白名单审核**、它的**副本已经开着**、它**已经关了**。

### 4.1 为什么关（D13，Aki 口述 2026-10-22，非公开来源）

1. **玩家 / 管理层 / 服主三方矛盾**，且"身份无关、两边不一定站一个阵营"；
2. **服主后期不重视运营**，几乎全交给几个管理员；
3. **人少，但 QQ 群还热闹**；
4. **起家靠"未境"清退的那批老玩家**，管理层多出自这批人。

仍未确认：具体关闭时间；第 4 条"清退→起家"的因果链 Aki 原句可两读。

### 4.2 结论：死于组织层，不是玩法层

三条归因里**没有一条涉及玩法内容**，反而说明社区还在（群还热闹）。
所以 T3 的结论方向定为**组织 / 排期线**，并单开 `_srv_PLAN.md` 3.4「治理：Aki 不在场的那六天」，
给三栏权责清单（A 只有 Aki 能定 / B 管理员自决 / C 必须公开）与「服主终裁 vs 民主投票」的未决张力（D15）。

### 4.3 三条推断（都是 `[推断]`，不是结论）

1. **"配方对"不保证"能活"。** 前面八个海外案例很容易让人得出"照这个组合做就行"，
   北岸枫林是反例。PLAN 1.2 里那两条张力（L1 靠留住会盖楼的人、L1 与 L3 受众冲突）
   不是理论风险，是已经发生过的事。
2. **赤物语的聚落制度比它薄一层。** 它是「聚落 → 达规模申请升级为**城镇** → 城镇徽章 + 传送石碑」，
   赤物语只有"聚落申请（≥5 人）+ 启动资金"。**等级化**比一次性审批更像 L1 的进度条。
3. **四个词不够用了**（见上一节）。

### 4.4 衍生的一条待决

**D14 · 要不要设入服门槛**：Waycraft、Cozy Homestead、北岸枫林、未寻旅境**四个同类样本全部有门槛**，
赤物语是唯一开放的。与 D7（正版验证，属合规）不同，D14 是"要不要筛人"的运营问题，两者可分开决定。
