# 服务器规则

赤物语是长期运行的公开服务器，规则一共十条。**进服即视为同意**；拿不准某件事能不能做，先在群里问一句，别先做了再解释。

::: warn 一句话版本
不作弊、不偷不抢不破坏、不卡服、不建难看的东西、不拿现实货币交易。严重的直接永久封禁 ID/IP。
:::

## 遵守国家法律法规

游戏内严禁任何违法犯罪活动，所有玩家的行为必须严格遵守法律法规。

这条是底线，也是其他九条的前提。涉及现实中的违法行为（诈骗、赌博、传播违禁内容等），不管发生在游戏里还是群里，一律直接封禁并保留追究的权利。

## 禁止发布违规内容

不得在服务器或相关平台内以任何形式发布任何违法、违规或带有欺诈行为的内容，包括但不限于色情、暴力、政治敏感话题。

「相关平台」包括服务器群、语音频道、告示牌、书籍、地图画、命名牌和建筑上的文字。**建筑和告示牌上的内容同样算发言**，不要用方块拼敏感图案。

## 尊重他人

- 保持文明，避免使用语言攻击他人。
- 禁止对任何人进行恶意嘲讽等不友好的行为。

吵架赢了不会得到什么，被记一笔是真的。真有过节找管理员，别在公屏对线。

## 禁止任何形式的作弊

包括但不限于飞行、矿透、杀戮光环、服务器 BUG。

| 常见说法 | 是否违规 |
|---|---|
| 飞行（鞘翅以外的悬停、Jetpack 类模组滥用） | 违规 |
| 矿透（X-Ray、透视材质包、区块工具看矿） | 违规 |
| 杀戮光环 / 自动攻击 / 自动钓鱼等外挂 | 违规 |
| 利用服务器 BUG 复制物品、刷钱、卡穿方块 | 违规，**主动上报有奖，隐瞒利用会被处理** |

模组整合包是统一发的那一份，自己往里加辅助类模组同样按作弊处理。

## 禁止偷盗 / 破坏他人财产

禁止偷盗 / 破坏包括但不限于任何他人的建筑、方块、生物、实体。

服务器安装了 **Ledger**，可以查询方块破坏与容器存取记录——谁放的、谁拆的、什么时候，都能查出来，别抱侥幸。

- 箱子、熔炉、展示框、盔甲架、宠物，只要不是你放的，就不是你的。
- 公共设施（出生点箱子、任务板、邮箱）可以用，用完放回去。
- 「不知道是谁的」不是理由。看着像没人要的东西，先在群里问。

## 禁止违规交易

- 禁止交易中出现欺诈行为，例如把改名的铁剑当成下界合金剑卖。
- 禁止使用现实货币（包括比特币、以太币等现实中的虚拟货币）进行交易。

服务器内的物品、货币、账号、代建**都不可以用现实货币买卖**。以物易物、游戏内货币交易不受限制，但别设局骗人。

::: note 关于「改名」
用铁砧改名的物品，鼠标悬停时仍显示原始材质。交易前让对方把物品丢出来看，或者截图留证——被骗了带着截图找管理员。
:::

## 限制红石 / 生电

为保证服务器稳定运行，禁止中大型红石机器 / 生电装置，包括但不限于：

- 村民交易所
- 刷怪塔
- 世吞（世界吞噬者）

并**禁止玩家使用活塞、粘性活塞、侦测器**。

小型红石（自动门、自动照明）不在此列，判断标准是「会不会让服务器卡」。不确定就把设计图发群里问。

## 限制地形破坏

禁止大规模的地形破坏。如需建造大型建筑，请合理规划地形。

挖空一整座山、把海抽干、在地表挖出一片采石场都算。平整地基是合理的，但请把范围控制在建筑轮廓内；挖出来的土石方别顺手倒进别人的风景里。

## 限制生物养殖

应保持适量养殖生物，过多的生物聚集会导致服务器卡顿。如果养殖大量生物，会被系统或管理员清理。

- 同一种动物一个围栏养十几只就够，不必按百只囤。
- 别用大量掉落物、经验球、船或矿车堆叠做装置。
- 被清理掉的生物不补偿，贵重生物（命名过、繁殖好的）别全塞在一个格子里。

## 建筑相关

- 禁止大型非装饰性建筑、地表农田、地图画、火柴盒、低俗建筑。
- 后续服务器人员增加会开放副世界，用于存放除低俗建筑以外的非美观性建筑，可临时居住。
- **不要在主城和景点附近建建筑。**
- 使用 `/rtp` 寻找居住地时，请多往周围走一走，确认附近没有别人的建筑，避免居住地冲突。

## 处罚

| 类型 | 行为 | 处理 |
|---|---|---|
| 需要整改 | 红石超标、生物过多、地形破坏、建筑不合规 | 提醒 + 限期整改，拆掉即可 |
| 一般违规 | 语言攻击、恶意嘲讽、违规交易（未造成实际损失） | 警告，再犯短期封禁 |
| 严重违规 | 作弊、偷盗、破坏他人财产、现实货币交易、违法内容 | **永久封禁 ID/IP** |

「严重者将会被永久封禁 ID/IP」不是吓唬人。刷物品、炸别人家、开挂，都是直接永久，不申诉。

## 有争议怎么办

1. 先看 **Ledger 记录**：方块和容器都有日志，事实比记忆可靠。
2. 找管理员私聊，附坐标、时间与截图，别在公屏刷。
3. 对处理结果不服，隔一天再申诉，不要在群里带节奏。
