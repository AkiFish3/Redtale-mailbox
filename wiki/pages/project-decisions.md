## 改名成本

| 改什么 | 成本 | 时机 |
|---|---|---|
| 项目名 / 仓库名 / 目录 / README | **零** | 随时 |
| jar 名、`archivesBaseName`、CurseForge 项目名 | 低 | 随时 |
| 包名（`com.xxx.yyy`） | 中，IDE 全局重命名 | 发版前 |
| **Mod ID / 命名空间** | **高** —— 物品、方块、属性、附魔、配置目录、datapack 路径、存档里的 ItemStack 全带它 | **上线后基本改不动** |
| 存档物品 | 极难（要写 NBT 迁移） | — |

结论：**名字随便改，ID 只能定一次**。`redtale_project` 已定，此后不再动。

**真实工作量在 MythicLib（2505 类）**，不在这五个插件本身 —— 属性注册表、伤害管线、占位符、兼容层全在它里面。

:::
