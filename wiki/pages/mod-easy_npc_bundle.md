> Bundle version of Easy NPC that automatically includes both the core mod and config UI mod using Jar-in-Jar technology. This bundle contains: - Easy NPC Core: Provides all NPC functionality - Easy NPC Config UI: Provides configuration interface for NPCs Users only need to install this single file to get both mods.

**Easy NPC: Bundle**（`easy_npc_bundle`）是**双端**模组，服务端与客户端整合包都带它。
