# 指令速查

都是聊天框里直接敲的斜杠指令。冷却时间按服里 `ftbessentials.snbt` 的现值写的，管理员随时能改，
以你实际敲的提示为准。

## 传送

| 指令 | 干什么 | 冷却 |
|------|--------|------|
| `/sethome` | 把当前位置设成家 | — |
| `/home` | 回家 | 10 秒 |
| `/spawn` | 回主城出生点 | 10 秒 |
| `/back` | 回到上次死的位置（也能回上一个传送点） | 30 秒 |
| `/tpa 玩家名` | 请求传送到对方身边 | 10 秒 |
| `/tpaccept` | 同意别人的传送请求（也可以点聊天栏里的按钮） | — |
| `/rtp` | 随机传送到远处未探索的地方 | 600 秒 |
| `/warp` | 传送到公共传送点（有哪些点由管理员建，空着就是还没建） | 10 秒 |

**只能设一个家**（`home.max = 1`）。想多留几个点，靠 `/warp` 或者记坐标。

`/rtp` 是探险开荒的主要手段：冷却长，但会把你丢到没被开发过的区域，落地先看脚下是水还是悬崖。

## 随身功能

不进工作台也能干活的一组：

| 指令 | 干什么 |
|------|--------|
| `/enderchest` | 打开自己的末影箱 |
| `/crafting` | 打开 3×3 工作台 |
| `/anvil` | 打开铁砧 |
| `/stonecutter` | 打开切石机 |
| `/smithing` | 打开锻造台 |
| `/trashcan` | 开一个垃圾桶，丢进去的东西直接消失 |
| `/hat` | 把手上物品戴到头上（纯外观） |

`/trashcan` 是真的删，别把要留的东西顺手丢进去。

## 社交

| 指令 | 干什么 |
|------|--------|
| `/near` | 看附近有哪些玩家 |
| `/nick 名字` | 改自己的显示名 |
| `/leaderboard` | 看排行榜 |
| `/kickme` | 自己退出服务器 |

## 用不了怎么办

- 提示「未知指令」→ 拼错了，或者该指令在服里被关了。
- 提示「冷却中」→ 等冷却走完，别连续敲。
- 完全没有反应 → 看 [[client|客户端与按键]] 的排查段，多半是客户端模组冲突。

更多问题看 [[faq|常见问题]]。
