# 客户端与按键

整合包预装了完整模组列表，这一页只说**你会天天用到的**那部分。

## 必用的三个

| 模组 | 干什么 | 默认按键 |
|---|---|---|
| **Jade** | 准星指着方块/生物时显示信息（含箱子内容预览、刷怪笼类型） | 自动显示，`小键盘 0` 调位置 |
| **REI**（Roughly Enough Items） | 物品/配方查询，`R` 查用途、`U` 查来源 | 物品栏里按 `R` / `U` |
| **Forgematica**（Litematica 的 NeoForge 版） | 建筑投影、选区、原理图 | `M` 打开主菜单 |

## 建造相关

**Forgematica** 是这套里最有用的一个：

- `M` → 主菜单 → 载入原理图，可以把网上下的建筑**半透明投影**到世界里，照着搭。
- 选区工具可以框一块地，存成原理图给别人。
- 它有个隐藏功能：**能把原理图导出成原版结构文件**，管理员做遗迹会用到（见管理员区的技术笔记）。

**Tweakerge**（Tweakeroo 移植）——一堆小开关，常用的：

- 精准放置（不会放歪）
- 快速拾取
- 禁止视角晃动

**BoccHUD**（MiniHUD 移植）——屏幕上叠信息：坐标、生物群系、光照、区块边界。搭建筑时开光照显示，能看出哪块会刷怪。

## 查找与辅助

**Rock'n Roller**（ItemScroller 移植）——背包里拖拽批量移动物品、一键整理。合成台里按住 `Shift` 滚轮可以快速移一整排。

## 常用原版按键提醒

| 按键 | 作用 |
|---|---|
| `F3` | 调试信息，**看维度 id 就靠它** |
| `F3 + G` | 显示区块边界 |
| `F3 + B` | 显示实体碰撞箱 |
| `F1` | 隐藏界面（截图用） |
| `~` | 任务书（如果被改过，看按键设置里的「FTB Quests」） |

## 按了键没反应怎么排查

按顺序走，绝大多数在第 2 步就解决了。

**1. 先确认不是输入法/焦点问题**

- 中文输入法开着时，部分按键被输入法吃掉。切到英文再试。
- 退出全屏、alt+tab 来回切一次，有时窗口没拿到键盘焦点。
- 笔记本外接键盘时，`Fn` 锁会让 F 区按键行为错乱。

**2. 查按键有没有被别的模组占了（最常见）**

- `Esc` → 选项 → 控制 → 按键绑定，搜你想用的那个键（比如 `M`、`R`、`B`）。
- **按键冲突会在那一行标红**（写「冲突」或两个功能共用同一个键）。改成别的键，或者把不用的那个清空。
- 列表最上面是「游戏内」和「界面」两套键位，同一个键在两套里可以分别绑，别只看一套。

**3. 确认模组装没装、开没开**

- 下面这些键是模组功能，整合包里都有，但可能被别的模组顶掉：
  - `R` / `U` → REI 查用途 / 查来源（**光标要悬停在物品上**才有反应，悬在空白处按没反应是正常的）
  - `M` → Forgematica 主菜单
  - `小键盘 0` → Jade 信息框位置
  - `~` → FTB 任务书（键位可能被改，搜「FTB Quests」）
- 单机测试时用 `F3` 看左上角模组数量，和服务器公告的数目对不上就是装漏了。

**4. 确认需要有目标才能触发**

- `R`/`U` 要指着物品；Jade 要准星对着方块/生物；Forgematica 的选区要先 `M` 里选好模式。
- 空手对着空气按，很多键本来就没反应，不是坏了。

**5. 还是不行的**

- 控制 → 按键绑定，把那个功能改成一个绝对没被用过的键（比如 `右 Ctrl + 字母`），能触发就是键冲突，不能触发才是模组问题。
- 到这里还不行，把 `Esc` → 选项 → 资源包/模组 列表截图发意见箱，别自己删模组装模组——服务端版本锁死，客户端动一个就连不上。

## 装不上 / 打不开

先确认你用的是整合包原版。**不要自己更新模组**——服务端是固定版本，客户端更新任何一个都会连不上。

整合包不带光影和渲染优化。想加光影需要自己装 Iris/Oculus 一类，但**出问题不负责**，先备份存档。
