# 如何进入

## 你需要什么

| 项 | 要求 |
|---|---|
| Java | **Java 21**（不是 8，也不是 17） |
| 客户端 | 整合包 `赤物语N客户端-0.0.1`，不要自己拼 |
| 内存 | 建议分配 6 GB 以上 |
| 版本 | Minecraft **1.21.1** + NeoForge **21.1.257** |

## 第一步：装客户端

整合包已经预装好 232 个模组，**不要删、不要自己加**。服务端和客户端的模组列表必须一致，少一个就会在连接阶段被踢。

导入方式（HMCL）：版本列表 → 安装新游戏 → 从本地整合包导入 → 选 `赤物语N客户端-0.0.1.zip`。

## 第二步：连服务器

在多人游戏里添加服务器，地址填群公告里的那个。端口默认 `25566`。

> 目前新服还在内测，只对内部开放。公开时间看群公告。

## 第三步：第一次进服

1. 进服后先**读任务书**（默认按键 `~`，或背包里的那本书）。
2. 出生点附近找管理员领**落地指引**——目前没有正式主城，别走太远。
3. 想建东西，先读「服务器规则」第十条：**别在主城和景点附近建**，用 `/rtp` 落地后多走一走，确认周围没有别人的建筑。

## 常见卡住的地方

**卡在「正在连接服务器」** —— 九成是模组版本对不上。确认你用的是整合包原版，没有自己更新过模组。

**进去一会儿被踢，提示版本不匹配** —— 同上，检查整合包是不是最新的那一份。

**内存不足闪退** —— 启动器里把内存调到 6~8 GB，别调 12 GB（反而更容易 GC 卡顿）。
