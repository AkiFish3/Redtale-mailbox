> Terraform Wood Api, but for forge

**Terraform Wood Api Reforged**（`terraform`）是**双端**模组，服务端与客户端整合包都带它。

<!-- auto:end -->

## 中文简介

木质方块 API（Terraform Wood API 的 NeoForge 重制版），把「一种新木材=一整套木板/楼梯/栅栏/门」的重复注册工作打包，让加了新树种的模组自动补齐全部木制品。玩家侧体现为某些树种的木制品能做全，纯前置，单独装没有内容。

## 在赤物语里

- 玩家侧：用不到，纯前置；装了加新树种的模组后，对应木材会自动出现完整的木制品系列。
- 服务端侧：无独立服务端配置文件；木种与配方由依赖它的模组通过数据包注册。
