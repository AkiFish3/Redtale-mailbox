# 待拍板

自动队列（S1 快照 / S2 规则 / S3 信箱 / S4 规划 / S5 地志）在跑的时候，凡是**必须你本人点头**的事都写在这一页。队列只记录、只等，绝不自己动手。

::: tip 怎么回
- 在每条的 `拍板：` 后面写结论，写 `A`、`B` 或一句话都行（比如「先开内置结构，两周后再看」）。
- 队列下一轮读到就会照办，并把这条挪到下面的「已定」区。
- 拿不准就留 `_待填_`，队列按该条的「默认」走，或者干脆不动。
- 要改主意，直接改「已定」里那条的结论即可。
:::

::: note 队列怎么写的
队列通过 wiki 的写入口（`POST /api/inbox`，令牌在 `data/inbox_token`）追加，不直接改文件、不启动任何服务。
所以你随时能看到最新条目，页面也不需要重启。
:::
