## Wiki 自身：常驻、待拍板、公网

### 常驻

Wiki 不再是「用完就关」的临时进程。现在由看门狗托管：

| 文件 | 作用 |
|---|---|
| `wiki_service.pyw` | 守护：`app.py` 退出 4 秒后自动拉起，连续 6 次秒退才放弃 |
| `启动.bat` | 手动启动（同样带守护循环），用于排查 |
| `停止.bat` | 停掉 wiki 与隧道 |
| `logs\service.log` | 启停记录，出问题先看这里 |

登录 Windows 后会自动拉起（启动文件夹里的 `RedtaleWiki.vbs`）。**不要再在对话里 `python app.py`** —— 那种进程会随会话被回收，表现为「用着用着就没了」。

::: warn 为什么以前会突然断
在 AI 会话里起的后台进程受会话生命周期管理，会话结束或超时就被杀。
现在进程挂在 explorer 下、由登录项启动，和任何对话都没关系。
:::

### 待拍板（S1–S5 队列找你签字）

五个自动队列遇到「必须你点头」的事，会写进本站的「待拍板」页（侧栏 → 管理员 → 待拍板）。

- 队列通过写入口 `POST /api/inbox` 追加，令牌在 `data/inbox_token`，不直接改文件、不启停服务。
- 你在页面上把每条的 `拍板：` 改成结论即可，**下一轮队列读到就照办**，并把这条挪到「已定」区。
- 留 `_待填_` 表示还没定，队列按该条的「默认」走或不动。

### 公网访问

本地 `http://127.0.0.1:8080` 只在本机；局域网用 `http://<本机内网IP>:8080`（app 绑的是 `0.0.0.0`）。

要让外网访问，用 Cloudflare 隧道（`tools\cloudflared.exe`，已下好）：

```
双击 公网访问.bat   →  地址写在 data\tunnel_url.txt
```

实测结果（2026-11-02）：

| 路径 | 结果 |
|---|---|
| `/login` | 200 |
| `/p/index`（游客可见页） | 200 |
| `/p/decisions`（admin 页） | 403（未登录） |
| `/api/inbox` | 403（缺令牌） |

::: warn 公网前的三件事
1. **登录只走 EasyAuth**：`data\users.json` 里建站时那两个演示号（`admin` / `redtale-admin`、`player` / `redtale`）已于 2026-11-02 删除，现在只有「游戏 ID + 进服密码」能登。公网开放前不要再建固定口令的本地号。
2. 快速隧道的域名**每次重启都变**，只适合临时给人看；要固定域名得用 Cloudflare 命名隧道（需要账号 + 域名）。
3. 隧道是 https 到 Cloudflare，最后一段到本机是明文；不要在这台机器上开别的无鉴权服务。
:::

### 服主怎么登

| 场景 | 做法 |
|---|---|
| 正常 | 用户名填游戏 ID `AkiFish3`，密码填**进服密码**。`data\mc.json` 的 `wiki_admins` 里有这个名字，首次登录自动建成管理员 |
| 忘了游戏密码 | 走「没有密码？用验证码」：填 ID → 拿到 4 位数 → 游戏里发 `wiki 0417`。服主 ID 走这条路同样给管理员 |
| 普通玩家 | 同上，登录后自动建号，权限是玩家；想去掉/调组在「用户管理」里改 |

::: note 为什么删掉旧账号
`do_login()` 的顺序是「先查 EasyAuth，失败再回落到 `users.json` 的本地密码」。
旧的 `admin` 号在 EasyAuth 里不存在，于是永远走回落分支——等于一个绕开游戏账号的固定口令。
本地密码机制本身要留着（验证码通道开的号靠它登录），所以只删了这两个条目。
:::
